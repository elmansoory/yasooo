الخطوة 1️⃣: فك الضغط
────────────────────────────────────────────────────────────────
🪟 Windows:
   - انقر مرتين على yasooo-complete.zip
   - أو استخدم: WinRAR, 7-Zip

🐧 Linux/Mac:
   tar -xzf yasooo-complete.tar.gz
   cd yasooo

الخطوة 2️⃣: التحقق من Python
────────────────────────────────────────────────────────────────
python --version
# أو
python3 --version

📌 يجب أن يكون Python 3.10 أو أحدث
📥 حمل من: https://www.python.org/downloads/

الخطوة 3️⃣: التشغيل السريع
────────────────────────────────────────────────────────────────

🎮 النسخة التجريبية (بدون تثبيت):
────────────────────────────────────────────────────────────────
python demo.py
# أو
python3 demo.py

✨ هذه النسخة تعمل مباشرة بدون تثبيت أي شيء!


💻 النسخة الكاملة (موصى بها):
────────────────────────────────────────────────────────────────
# 1. تثبيت المتطلبات (مرة واحدة فقط)
pip install -r requirements.txt
# أو
pip3 install -r requirements.txt

# 2. تشغيل التطبيق
streamlit run app.py

# 3. افتح المتصفح على:
http://localhost:8501

🎯 الميزات الرئيسية
═══════════════════════════════════════════════════════════════

✨ تحليل ذكي للوضعيات:
   - كشف 33 نقطة مفصل
   - حساب الزوايا والمسافات
   - تتبع مركز الكتلة

📊 تسجيل وفق معايير ISU:
   - 24 قفزة (Single → Quad)
   - 7 أنواع دورانات × 5 مستويات
   - GOE من -5 إلى +5
   - 5 مكونات برنامجية

🎥 معالجة فيديو متقدمة:
   - دعم MP4, AVI, MOV, MKV
   - تحسين الإضاءة
   - إزالة الضوضاء

💾 قاعدة بيانات شاملة:
   - تتبع المتزلجين
   - حفظ التحليلات
   - إحصائيات متقدمة

═══════════════════════════════════════════════════════════════
🐛 حل المشاكل الشائعة
═══════════════════════════════════════════════════════════════

مشكلة: "command not found: python"
────────────────────────────────────────────────────────────────
الحل:
   - استخدم python3 بدلاً من python
   - أو ثبت Python من python.org


مشكلة: "No module named 'streamlit'"
────────────────────────────────────────────────────────────────
الحل:
   pip install streamlit
   # أو
   pip install -r requirements.txt


مشكلة: البرنامج بطيء
────────────────────────────────────────────────────────────────
الحل:
   - استخدم النسخة التجريبية (demo.py)
   - أو قلل جودة الفيديو
   - أو استخدم skip_frames في الكود


مشكلة: خطأ في MediaPipe
────────────────────────────────────────────────────────────────
الحل:
   pip install mediapipe --upgrade
