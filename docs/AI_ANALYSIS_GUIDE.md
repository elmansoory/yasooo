# 🤖 دليل نظام التحليل بالذكاء الاصطناعي
# AI Analysis System Guide

## نظرة عامة

نظام تحليل متقدم لفيديوهات التزلج الفني باستخدام تقنيات الذكاء الاصطناعي والتعلم الآلي.

---

## 🎯 الميزات الرئيسية

### 1. كشف الوضعيات (Pose Detection)
- تتبع 33 نقطة رئيسية في الجسم
- دقة عالية باستخدام MediaPipe
- تتبع في الوقت الفعلي
- كشف حالة الطيران (Airborne Detection)

### 2. كشف وتصنيف القفزات
- **أنواع القفزات المدعومة:**
  - Axel (1-4 دورانات)
  - Lutz (1-4 دورانات)
  - Flip (1-4 دورانات)
  - Loop (1-4 دورانات)
  - Salchow (1-4 دورانات)
  - Toe Loop (1-4 دورانات)

- **المقاييس المحسوبة:**
  - عدد الدورانات
  - ارتفاع القفزة (cm)
  - المسافة المقطوعة (cm)
  - وقت الطيران (seconds)
  - سرعة الدوران (RPM)
  - زاوية الإقلاع والهبوط

### 3. تحليل الدورانات (Spins)
- أنواع الدورانات: Upright, Sit, Camel, Layback, Combination
- حساب عدد الدورانات
- حساب السرعة (RPM)
- تحديد المستوى (Level 1-4)

### 4. تقييم GOE التلقائي
- تقييم حسب معايير ISU
- نطاق التقييم: -5 إلى +5
- **العوامل المُقيّمة:**
  - وضوح الحافة (Clear Edge)
  - اكتمال الدورانات (Full Rotations)
  - جودة الارتفاع (Good Height)
  - الانسيابية (Good Flow)
  - نظافة الهبوط (Clean Landing)

### 5. حساب النقاط حسب ISU
- قيم أساسية (Base Values) حسب ISU
- إضافة/خصم GOE
- حساب النقاط الإجمالية

### استخدام برمجي (API)

```python
from src.ai.advanced_analyzer import AdvancedSkatingAnalyzer

# إنشاء محلل
analyzer = AdvancedSkatingAnalyzer()

# تحليل فيديو
results = analyzer.analyze_video("path/to/video.mp4")

# الوصول للنتائج
print(f"عدد القفزات: {len(results['jumps'])}")
print(f"النقاط الكلية: {results['total_score']:.2f}")

# تفاصيل كل قفزة
for jump in results['jumps']:
    print(f"نوع: {jump.jump_type.value}")
    print(f"دورانات: {jump.rotations:.1f}")
    print(f"ارتفاع: {jump.height_cm:.1f} cm")
    print(f"GOE: {jump.goe:+d}")
    print(f"نقاط: {jump.final_score:.2f}")
```

## 📊 فهم النتائج

### بنية بيانات القفزة (Jump Analysis)

```python
JumpAnalysis(
    jump_type=JumpType.LUTZ,
    rotations=3.0,
    height_cm=65.5,
    distance_cm=120.0,
    airtime_seconds=0.65,
    rotation_speed_rpm=277,
    
    # GOE factors
    has_clear_edge=True,
    has_full_rotations=True,
    has_good_height=True,
    has_good_flow=True,
    has_clean_landing=False,
    
    # Scores
    base_value=5.90,
    goe=+2,
    final_score=7.90,
    
    # Metadata
    start_frame=150,
    end_frame=180,
    confidence=0.92
)
```

### تفسير GOE

| GOE | المعنى | الوصف |
|-----|--------|-------|
| +5 | ممتاز جداً | أداء استثنائي بجميع المعايير |
| +3 | ممتاز | أداء ممتاز مع عدة عوامل إيجابية |
| +1 | جيد | أداء جيد مع بعض الإيجابيات |
| 0 | متوسط | أداء مقبول بدون مشاكل كبيرة |
| -1 | ضعيف | بعض المشاكل الصغيرة |
| -3 | سيء | مشاكل واضحة |
| -5 | سيء جداً | فشل في التنفيذ |

### تفسير النقاط

- **Base Value:** القيمة الأساسية حسب نوع العنصر وصعوبته
- **GOE:** التعديل حسب جودة التنفيذ
- **Final Score = Base Value + GOE**

## 🎓 خوارزميات التحليل

### 1. كشف القفزات

```
1. كشف تسلسلات الطيران (Airborne Sequences)
   - تحليل ارتفاع القدمين
   - الحد الأدنى: 5 إطارات

2. تحليل كل تسلسل:
   - حساب المدة الزمنية
   - تقدير الدورانات من السرعة الزاوية
   - حساب الارتفاع من الموضع العمودي
   - تحديد إطارات البداية/القمة/النهاية

3. تصنيف نوع القفزة:
   - تحليل وضعية الإقلاع
   - تحليل استخدام القدم
   - تحليل زاوية الجسم
   - مقارنة مع نماذج مدربة

4. حساب GOE:
   - فحص كل عامل جودة
   - جمع النقاط الإيجابية/السلبية
   - تحويل للمقياس ISU (-5 إلى +5)

5. حساب النقاط النهائية:
   - الحصول على Base Value من جدول ISU
   - إضافة GOE
```

### 2. كشف الدورانات

```
1. كشف تسلسلات الدوران (Spinning Sequences)
   - تحليل الحركة الدورانية
   - حساب السرعة الزاوية

2. تصنيف نوع الدوران:
   - Upright: وضعية واقفة
   - Sit: وضعية جلوس
   - Camel: وضعية الجمل
   - Layback: انحناء للخلف
   - Combination: خليط

3. حساب المقاييس:
   - عدد الدورانات
   - RPM (دورة في الدقيقة)
   - المدة الزمنية
   - مركزية المحور

4. تحديد المستوى (Level):
   - Level 1: أساسي
   - Level 2: متوسط
   - Level 3: متقدم
   - Level 4: خبير
```

## 🔬 التقنيات المستخدمة

### MediaPipe Pose
- **الوظيفة:** كشف 33 نقطة رئيسية في الجسم
- **الدقة:** عالية جداً (>95%)
- **السرعة:** في الوقت الفعلي
- **المتطلبات:** CPU/GPU

### OpenCV
- **الوظيفة:** معالجة الفيديو وتحليل الإطارات
- **الاستخدامات:**
  - قراءة/كتابة الفيديو
  - تحويل الألوان
  - تحسين الصورة

### NumPy
- **الوظيفة:** الحسابات الرياضية
- **الاستخدامات:**
  - حساب الزوايا
  - حساب المسافات
  - تحليل السرعة

### TensorFlow/PyTorch (اختياري)
- **الوظيفة:** التصنيف المتقدم
- **الاستخدامات:**
  - تصنيف أنواع القفزات
  - تحسين دقة الكشف
  - التعلم من البيانات الجديدة

## 🐛 استكشاف الأخطاء

### مشكلة: "MediaPipe not installed"

**الحل:**
```bash
pip install mediapipe>=0.10.8
```

### مشكلة: "Low detection confidence"

**الحل:**
- تأكد من جودة الفيديو (720p على الأقل)
- تأكد من وضوح الإضاءة
- تجنب الزوايا المائلة جداً
- خفض `confidence_threshold` في الإعدادات

### مشكلة: "Out of memory"

**الحل:**
- استخدم `frame_skip` أكبر
- قلل دقة الفيديو قبل المعالجة
- أغلق البرامج الأخرى
- استخدم GPU إذا كان متاحاً

### مشكلة: "Video processing too slow"

**الحل:**
- زد `frame_skip`
- قلل دقة الفيديو
- استخدم GPU
- عالج أجزاء من الفيديو
