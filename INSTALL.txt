===============================================================
⚡ Quick Start (3 minutes)
===============================================================

Step 1: Extract
───────────────────────────────────────────────────────────────
Windows:
  - Double-click yasooo-complete.zip
  - Or use WinRAR/7-Zip

Linux/Mac:
  tar -xzf yasooo-complete.tar.gz
  cd yasooo

Step 2: Verify Python
───────────────────────────────────────────────────────────────
python --version  # Should be 3.10+

Download from: https://www.python.org/downloads/

Step 3: Run!
───────────────────────────────────────────────────────────────
Option A - Demo (No installation required):
  python demo.py

Option B - Full Version:
  pip install -r requirements.txt
  streamlit run app.py
  # Open: http://localhost:8501

===============================================================
🎯 Features
===============================================================

✨ Smart Analysis:
   - 33 body landmarks detection
   - Angle & distance calculation
   - Center of mass tracking

📊 ISU Scoring:
   - 24 jumps (Single → Quad)
   - 7 spin types × 5 levels
   - GOE (-5 to +5)
   - 5 program components

💾 Database:
   - Track skaters
   - Save analyses
   - Statistics & reports
